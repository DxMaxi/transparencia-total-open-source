# Código de conduta

Este projeto acolhe contributos independentemente de identidade, ideologia ou filiação partidária.
Exige-se comunicação respeitosa, foco em evidência verificável e aplicação simétrica das regras.

Não são aceites assédio, ataques pessoais, propaganda partidária, manipulação seletiva de fontes,
publicação de informação privada ou tentativas de pressionar revisores a alterar conclusões sem
evidência oficial. Os responsáveis podem moderar ou excluir contributos que violem estas regras.
